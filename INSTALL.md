### [tuicr](https://tuicr.dev)

#### Install using Git

If you are a git user, you can install the theme and keep up to date by cloning the repo:

```bash
git clone https://github.com/dracula/tuicr.git
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/dracula/tuicr/archive/master.zip) option and unzip them.

#### Activating theme

1. Find your `tuicr` themes directory located in `~/.config/tuicr/themes` (create the directory if it does not exist).
2. Copy `dracula.toml` and `dracula.tmTheme` to `~/.config/tuicr/themes/`.
3. In `~/.config/tuicr/config.toml`, set `theme = "dracula"`.
